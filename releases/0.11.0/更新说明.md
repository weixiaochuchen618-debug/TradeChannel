# 0.11.0 预览版更新说明

基线：0.10.2。实现第七轮部署与连接方式优化，验收按配置、运行、网络路径和业务分层报告。

## 单线路与连接配置

新增 LineStore：稳定 LineId、UDP/TCP profiles、不可变配置 revision、独立验证证据及历史 alias。TCP 补齐加入原线路，不创建兄弟节点。旧兄弟记录须来源标记、配置哈希、服务器/设备身份、地址与策略均匹配才归并。

只读展示不改变现用 manifest、偏好或部署引用。资料整理在独立目录生成并校验配置，正式切换由运行事务提交。旧版 UI/CLI 不支持新模型时不应混用，程序降级需核对数据兼容性。

## 部署与补齐

标准 Auto 实际串联 UDP 基础、管理能力、一次设备授权、可选 TCP 检查和增量准备、原设备参数、本机双 profile 及顺序验证。TCP 普通失败复核 UDP 后警告交付；未知事务、身份漂移或恢复未完成不包装成成功。

云规则以一张清单列出管理、UDP 和最终 TCP 端口。443 占用时检查受控候选，不停用外部服务。普通页面隐藏技术参数，管理会话与已保存凭据复用。入口和握手/客户端验证分别记录。

新电脑 V1 邀请、请求和签名授权保留严格字段契约。验签后的本机 ConnectionBundle 保存双方式描述；敏感部分沿原加密交接与受限目录保存，不向新电脑提供服务器管理凭据。

高级 Linux 新部署与新增授权入口导向统一向导，保留历史任务、状态和恢复诊断。

## 切换与恢复

ConnectionTransactions 提供预览批准和持久化阶段。明确选择 profile 时核对目标自建出口、原进程归属、配置/偏好哈希、交易软件退出状态和锁。

停止原会话、提交目标、启动并实测外网；失败停止候选、恢复资料和意图，原来运行则重连复测，原来未连接则保持未连接。停止或恢复失败进入 NeedsRecovery，禁止重复引擎。配置恢复不冒充连接或业务恢复。

保持 A 方案的受控重连。B 独立回环实验发现未选路径、keepalive 和探测会影响转发；本版不提供静默自动切换，不承诺无中断。

## 升级与边界

完整包包含启动器、引擎、WireGuard 工具、管理执行器和固定依赖。不从旧包拼文件；保留旧程序和现有数据备份。

开发不切换现用电脑线路。隔离测试、回环协议、真实服务器候选、Windows 接管和交易业务分别记录。交付报告明确未执行项，不以启动器断言数量替代生产验收。

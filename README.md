# TradeChannel 交易通道

Windows 桌面通道与分流管理项目，包含 PowerShell、C#、Python、WPF 界面、Linux 部署代码、构建工具和测试。

**最新源码：0.16.17 预览版。** 本仓库保存脱敏后的完整项目源码，包括 `product/` 历史基线和 `releases/` 下的全部 34 个版本。当前仓库由所有者选择公开，最新源码为预览版。构建验证、程序安装与真实服务器端到端验收分别记录。

第一次使用 GitHub，请先看 [GitHub 新手指南](docs/GitHub新手指南.md)。构建与验证方法见 [源码构建说明](docs/源码构建说明.md)，隐私处理见 [脱敏说明](docs/脱敏说明.md)。

本次新增 0.16.15、0.16.16 和 0.16.17 源码；首页读取、删除预览刷新、输入焦点与旧回退清理等变更见 [更新记录](CHANGELOG.md)。

## 项目能力

- 分别管理交易、日常上网和 AI 助手流量的出口。
- 自建服务器部署、SSH 身份核验、设备配对和线路管理。
- UDP/TCP 检测、默认协议选择、连接证据与失败恢复。
- 本地配置事务、运行诊断、线路保护和资料清理。

交易流量可按用户选择走自建线路或可用的服务商线路；日常流量也可选择本地直连。具体功能以当前版本源码与随版本指南为准。

## 使用与构建

运行环境是 Windows x64、Windows PowerShell 5.1 和 .NET Framework 4.8。网络及安装操作需要管理员权限。

本仓库中的可执行文件、第三方 DLL、安装器、压缩包和个人运行配置已排除。下载源码 ZIP 后不能直接双击运行，需要先按 [源码构建说明](docs/源码构建说明.md) 准备固定版本的依赖，再构建完整包。

当前版本用户指引：[新手部署指南](releases/0.16.17/新手部署指南.md)、[Linux 部署指南](releases/0.16.17/Linux部署指南.md)、[更新说明](releases/0.16.17/更新说明.md)。历史文档中的版本状态和工作区报告链接只作为历史背景；原始现场报告含私有运行信息，没有上传。

# 0.14.0 界面与状态呈现更新

- 统一蜘蛛品牌图标：标题栏、窗口、启动器、快捷方式；托盘使用运行、过渡、待核对、故障四种呈现，故障保留感叹号与意外中断提醒。
- 主图标固定白色；状态图标只概括交易通道运行，不代表交易或 AI 平台全部可用。
- 概览顶部改为紧凑状态摘要，显示线路、当前 UDP/TCP 与交易保护；保留流量走向的蓝色勾选和三类功能图标。
- 各流量行显示本行出口证据和时间；AI 明确标注按分流规则跟随，不冒充平台访问验收。
- 出口检查绑定会话、配置、线路、协议和分流选择；检查期间改变上下文、换线、重连或过期后，旧 IP 不再作为当前结果展示。
- 使用状态、连接时检查、当前出口检查和业务可用性分开呈现；保留明确的“检查未通过”和诊断入口。
- 正常状态详情折叠，故障、保护不完整或服务商异常时展开。关闭与托盘恢复继续沿用既有“连接保持”逻辑。

图标含 16/20/24/32/40/48/64/128/256 九档原生尺寸，16–24px 使用 SVG 简化稿。Runtime 没有新增浏览器或 SVG 渲染依赖。

本版本不改变连接事务、UDP/TCP 准备、分流规则或服务器部署行为。完整 Windows x64 预览包可直接解压；安装更新仅替换程序文件。

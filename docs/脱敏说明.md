# 上传范围和脱敏说明

本次按 2026-10-15 的开发目录整理，最新源码版本为 0.16.12。

## 包含和排除

包含 `product/`、全部 29 个 `releases/` 版本、`tools/` 和 `design-handoff/` 中的源码、测试、指南、图标及许可文本，保留固定依赖锁定清单。

排除以下内容：

- 真实运行配置、节点身份、凭据、私钥和导出文件。
- 原始 `reports/`、登录排查日志、现场截图及安装回退备份。
- EXE、DLL、压缩发行包、NuGet 下载缓存、测试库、测试运行产物与 Python 缓存。
- 原上传准备目录及既有 Git 历史，防止旧文件或旧提交元数据携带隐私信息。

这份仓库保存完整项目源码，不是电脑工作目录的逐文件镜像，也不是个人运行资料备份。

## 替换原则

真实服务器和曾观察到的出口地址统一替换到 RFC 5737 文档网段 `203.0.113.0/24` 或 `198.51.100.0/24`；源码与测试断言同时替换。个人工作区路径改为相对路径，涉及本机账户的测试路径改为 `ExampleUser`，真实机器名改为示例名。

要求通过“公网地址”校验的隔离测试采用公开 DNS 地址 `1.1.1.1` 和 `1.0.0.1` 作为模拟值；相关网络调用由测试替身接管。非规范地址用例保留前导零，仍验证拒绝行为。没有为脱敏放宽生产代码的地址校验。

公共 DNS、标准网段、公开服务域名、第三方作者署名、版权邮箱和依赖校验哈希保留。模拟测试口令、随机生成的隔离测试身份、私钥格式标记用于测试安全处理，不属于可连接真实服务器的凭据。

## 提交与后续保护

从脱敏后的干净快照建立 Git 历史，使用 GitHub `noreply` 邮箱提交。仓库设置为私有；未添加协作者、未发布可执行程序。

`.gitignore` 排除常见凭据、日志和构建产物，但不能识别写进源码里的新秘密。每次更新仍需扫描和复查，不能只依赖仓库私有性或忽略规则。

检查结论与具体覆盖范围见同目录的 `上传验证记录.md`。没有上传原始现场报告，其中的历史文件链接只作本机历史引用。

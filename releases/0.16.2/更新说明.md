# TradeChannel 0.16.2 连接与恢复补丁

- 修复旧线路升级后提示 `SavedDefaultMissing`：没有新版默认字段、但旧记录明确保存过的默认方式继续沿用，并核对原配置、设备身份与哈希。新版明确清空的默认不自动补回；确实缺少默认时提供“查看连接方式”入口。
- 修复旧香港主线的检测文件仅含隧道 DNS 时，重新检查报“检测准备失败”的兼容问题。新检测副本补齐主配置已有的直接 bootstrap DNS，保留原文件及隧道 DNS 检查路径。
- 修复 SSH 断线误判为密码问题：连接中断优先复用同一任务、目标、账户与已信任指纹下的有效登录信息，最多自动重连两次。手动“重试连接”与“修改登录资料”分开，页面显示中断步骤和已保存配置。
- 凭据仍只在内存短期保留；使用此前主动加密保存的凭据时也核对相同目标。认证拒绝不反复重试，身份变化不自动信任，未知错误不默认归为密码错误。
- 断线前可能已执行的部署、授权或 TCP 准备先核对远端结果，保留原运行与批准范围，不自动重放变更。
- 修复 Windows PowerShell 5.1 下无 BOM UTF-8 配置含中文网卡名时，出口检查解析失败的问题。切换前预检与实际出口检查共用读取和检查逻辑，配置或网卡不符合条件时在断开旧线路之前阻止切换。
- 连接失败分别呈现失败原因、恢复状态和后续操作。新事务日志保存固定错误码与阶段，不写入配置原文、密码或密钥；旧事务的原始错误也不再直接展示。

保留 0.16.1 的部署中心与操作历史记录管理、单条/多选/全选删除、恢复记录、服务器与设备入口及技术工具。安装更新只替换程序，用户线路、密钥和原始记录保留。

版本使用 Windows PowerShell 5.1 与 .NET Framework 4.8。源码、隔离流程、本机真实 SSH、WPF、完整 ZIP、安装版及真实公网验证分别记录，具体执行结果以本版交付与验证说明为准；通用网络检查不代表交易账户、行情或订单验收。

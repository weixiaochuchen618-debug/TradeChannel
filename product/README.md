# TradeChannel 0.8.0 · 交易通道控制台（预览版）

完整解压后双击 **TradeChannel.exe**，允许 Windows 管理权限。打开界面只读取状态，不会自动连接或切换网络。双击包内 **创建桌面入口.cmd**，或在「设置」页创建桌面快捷方式。请保持解压目录固定。

- 从 [快速部署.html](快速部署.html) 开始，或阅读 [新手部署指南.md](新手部署指南.md)。
- 新购低配 Linux VPS 可从本机打开「部署 → 部署 Linux 服务器」，按 [Linux 部署指南](Linux部署指南.md) 检查、生成计划、安装与授权。新节点只进入导入流程，不自动替换当前线路。
- 更换 VPN 服务商、Clash Verge 自动准备与回退见 [服务商接入](服务商接入.md)。
- 交易电脑由内置 sing-box 实现 WireGuard 协议，无需打开旧 WireGuard 窗口；包内 `wg.exe` 是配置工具。
- 转发服务器仍需 WireGuard 服务。向导提供「使用随包安装程序」和「从官网下载并安装」，执行前校验官方签名；随包 EXE 是联网引导器。

## 界面

| 页面 | 负责什么 |
|---|---|
| 概览 | 连接 / 断开；**交易**（自建或服务商备用）、**日常上网**（直连 / 所选服务商 / 交易线路）、**AI 助手**（跟随日常 / 交易线路）；实际出口与保护状态 |
| 线路 | 自建节点、AI 助手名单、服务商登记与检查、客户端自动准备与恢复 |
| 部署 | 交易电脑与转发服务器分步部署、设备授权、换电脑迁移 |
| 设置 | 登录后打开控制台、窗口行为、解除保护 |

交互规则：日常上网和 AI 助手的选择点击即生效，不影响交易连接；切换交易线路会先确认，因为现有交易连接会中断；未连接时任何选择只保存为下次连接使用。

## 0.8.0 Linux 部署预览

- 支持从本机通过 OpenSSH 准备 Ubuntu 24.04 / Debian 13 x86_64 专用 VPS；首次主机指纹和密码在独立登录窗口输入。
- Linux 后端检查环境，生成可审阅计划，安装原生 WireGuard、限定网段的转发/NAT 和开机服务；管理记录用于重复执行及失败恢复。
- 客户端密钥留在 Windows，服务端密钥留在 Linux。部署完成后核对公开授权，再交给现有节点导入向导。
- 可查看近期部署任务，为新电脑添加独立设备授权。不会自动换线或把服务器安装完成标记为交易已验收。
- 当前仍为预览版；真实系统、重启和交易稳定性应按目标节点分别验收，不能用隔离测试代替。

## 0.7.3 修复

- 修复全局启动后无法回到交易分流：生成配置明确声明 `global` 和 `rule`，不依赖启动默认值来决定可切换范围。
- 切换前检查引擎支持的模式；未支持时不发切换请求、不清缓存、不关闭连接。回读确认成功后才让需要换出口的日常连接重连。
- 服务商连接状态以最新检测为准，避免旧检查记录锁住已重新连接的客户端。已应用配置不等于客户端正在运行。
- 旧配置需要在维护窗口重新生成并加载；仅替换界面或重启同一份旧配置不能修复模式缺失。

## 0.7.1 变化

- 服务商不再限定 BatVPN：可登记 Clash Verge、BatVPN 和其他本机 SOCKS5 客户端。
- 日常选择和交易备用选择独立；日常服务商变更不会顺带切交易。未知或未应用的服务商不会悄悄替换为第一个档案。
- Clash Verge 自动准备前备份；配置冲突或使用中会给出具体提示，保留当前通道。
- 新增端口需要配置 v4 和一次明确的维护升级；登记、检查、打开控制台不会自动升级或断开香港。
- 已应用的日常服务商可快速切换。交易备用仍需先验出口和历史行情，不做自动故障切换。

## 0.6.0 已有功能

- **AI 助手名单**：所选助手可以单独走交易线路，其他日常流量照常走 BatVPN 或本地网络，不必再把整台电脑切到「走交易线路」。
  - 预置 Mirasim、Claude Code 与 Claude 桌面版、Codex（桌面版与命令行）、Google Antigravity（反重力）、CC Switch（接口中转）、Claude 网页版、ChatGPT 网页版、Gemini 网页版，可逐项开关，也可添加网址或程序。
  - 桌面程序按程序识别；网页版只匹配浏览器访问所列网址。
- **立即生效**：切换和改名单都立即生效，不重启通道、不中断交易连接；只重连路线确实改变的助手连接。
  - 名单走交易线路时，名单网址也经交易线路解析 DNS。
- **不影响交易**：名单规则排在交易与全局规则之后，不会改变 NinjaTrader、TradingView、Tradovate 的走向，也不会把 BatVPN 自身放进隧道。
- **需要升级线路配置**：需要线路配置 v3，旧配置可在概览页一键升级（原配置保留，升级时需退出 NinjaTrader）。
- **界面与构建修正**：
  - 交易线路名较长时按钮显示短名，全名在悬停提示和状态行中；
  - 出口检查以 `1.1.1.1` 测量响应时间；
  - 控制台打开时也能重新构建程序包。

## 0.5.0 变化

- **通道更稳**：系统代理被任何程序修改时，守护程序立即暂停该代理并记录，不再停止通道；偶发的状态读取失败只记录，不停机。
- **日常上网可走 BatVPN**：启用前核验 BatVPN 端口属于其安装目录、没有其他虚拟网卡，并实际测试转发；不满足时保持直连，恢复后自动切回，不会形成回环。

## 边界

重启后默认手动连接；「登录 Windows 后打开控制台」只打开界面。手动断开保留 NinjaTrader 持久保护；关闭窗口收起到托盘，通道继续运行。没有自动故障切换。

浏览器按交易域名分流，不具备 NinjaTrader 的整进程断网保护。工具不登录交易账户、不下单。

AI 助手名单只为名单内网址改用交易线路 DNS。桌面助手访问名单以外、在本地被屏蔽的网站可能失败：可以把网址加入名单，或临时切到「走交易线路」。

第二台 Windows Server/客户端、真实登录任务、签名安装器与正式服务仍待对应环境验收。包内 `package.sha256` 用于发现文件缺失或被修改，不等于代码签名；修改源文件后需重新构建。

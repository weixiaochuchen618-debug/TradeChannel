# 0.14.1 运行图标同步修复

任务栏新增状态徽标，与Windows窗口图标及托盘图标统一使用同一份交易通道状态：

- 绿色：通道运行中。
- 琥珀色：正在连接、切换或断开。
- 灰色：未连接、尚未配置或状态待核对。
- 灰色加感叹号：连接状态需要处理。

任务栏以品牌图标右下角的状态徽标表示运行情况：绿勾、琥珀时钟、灰色横线及故障感叹号。使用Windows支持的状态叠加接口，适配应用分组及固定入口，不更改应用ID、快捷方式或任务栏设置。窗口及托盘蜘蛛随状态变色；状态变化、窗口建立、收起与恢复沿用同一映射，普通状态轮询不会重复注册托盘。

自检采用独立的Windows应用标识，模拟状态不会覆盖正在运行的任务栏分组。标题栏品牌标识和桌面启动入口保留固定白色；运行时颜色只反映交易通道，不代表所有业务可用。Windows“小图标任务栏”模式不显示状态叠加，仍可从托盘和概览查看状态。

仅调整显示及本机图标诊断记录，连接、分流、服务器与网络配置不变。

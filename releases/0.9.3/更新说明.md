本版处理六项使用反馈，完整包已包含启动器和所有二进制。

- **服务商管理**：线路页可添加、编辑、刷新客户端路径、删除档案。正在承载流量的档案不能修改或删除；删除不卸载客户端、不删除订阅。

- **交易域名**：线路页“管理交易域名”可添加、移除、恢复默认。保存用于新节点；已有线路的当前规则保持，退出 NinjaTrader 后通过设置页维护更新应用。
- **任务管理**：部署页可归档/恢复已结束任务，查看归档。归档仅改变列表标记，密钥、配置、授权与恢复记录都保留；执行中的任务不能归档。

下列为继承的 0.9.2 操作和验证边界：

## 0.9.2 已有能力

这是完整 Windows x64 预览包，包含启动器、连接引擎、WireGuard 配置工具及服务器安装引导器。全部解压到固定目录后运行 `TradeChannel.exe`，无需现场编译或从旧版本补文件。打开控制台只读取状态；连接、断开、换线和维护由你操作。

## 本次迭代

- 旧 TCP 注入配置升级时，从原 VLESS/Reality 出站迁移每服务器参数，保留 WireGuard 身份与路由；新增出站依赖检查。
- TCP/UDP 修改使用独立候选配置，candidate 和 probe 均验证后提交。校验失败不改变原文件、索引或已选择的线路；成功后原配置保留。
- 当前线路正常断开后可以修改协议或删除；运行中或清理未完成时拒绝修改。
- 删除仅清理本工具可核实独占的节点目录。接管的原目录和无关资料保留；文件被占用时不报告成功。
- 自动部署导入使用明确的任务上下文，保留路径、名称和新节点 ID；导入后需要你确认才切换。
- 新服务器缺少原服务商时，可回落自建交易出口、日常直连，并显示原因；失败恢复完整偏好，不选用另一交易服务商。
- Linux 专用 VPS 可在生成计划前选择 TCP。后端下载并校验固定官方 sing-box 1.14.2、生成该服务器专属 Reality 身份、建立独立服务，只允许中继本节点 WireGuard。新增设备不会重启传输服务或更换服务器身份。
- 已有 TCP 服务器的参数在“线路 → 开启 TCP”表单填写，逐节点保存。没有固定 UUID/公钥供任意服务器套用。
- 服务器归属和配置验证决定“已部署”状态。阻断问题保留显示；Status 任务不能代替原申请生成客户端私钥。
- 失败和结果未知的任务保留在近期列表。恢复工具默认只读，维护只使用已核实的项目停机路径，不按进程名杀程序、不禁用其他网卡、不删除部署记录。
- 指纹重置按 host 与端口调用系统 OpenSSH 工具，保留备份，支持哈希记录；相似地址和其他端口保留。
- 诊断正确解析 IPv4/IPv6，检查配置依赖与完整性、本机密钥，并测实际 TCP 端口的建连耗时；不把 TCP 管理端口无响应解释成 UDP 服务器离线。

## 使用已有线路

1. 把完整包解压到新固定目录，保留旧目录作为回退。打开新控制台会读取现有受限数据目录，不自动切换线路。
2. 已经由外部脚本注入 TCP 的节点可在维护窗口更新线路配置，或填写该服务器已有参数。旧配置及服务端身份保留。
3. 修改正在使用的线路之前，先退出整个 NinjaTrader、正常断开该线路。保存新配置后再手动连接；切换会中断现有连接。
4. 回退程序可打开保留的旧版本。若同时回退节点配置，使用保留的 PreviousManifestPath/原节点资料，不能只把新配置的校验值改回旧值。

不建议同时运行两个控制台操作同一个通道。不要在 ZIP 内、临时解压目录启动，也不要把新包覆盖到正在运行的目录。

## Linux TCP 新部署

目标是 Ubuntu 24.04 或 Debian 13 amd64、带 systemd 的专用 VPS。输入公网 IPv4、SSH 资料，勾选 TCP，填写 TCP 端口及可从服务器访问的 TLS 1.3 伪装域名。环境检查通过后审阅计划，在云控制台放行计划中的 TCP 端口并保留 SSH 管理入口，再应用。

服务器需要能访问发行版软件源、固定官方 GitHub 下载及指定伪装域名。端口已被占用时停止；不会覆盖其他服务。客户端下载参数来自对应服务器的公开授权回复，Reality 私钥留在服务器，客户端 WireGuard 私钥留在本机。

SSH 密码与首次指纹核对在独立登录窗口完成。当前 Windows OpenSSH 流程每步骤可能重新询问密码；已有 SSH 私钥可在向导选择。此版本不声称 ControlMaster 复用或“只输入一次密码”。

已有 Windows Server 的自动部署仍为原生 UDP。已有 TCP 服务可填写连接参数；本版本没有 Windows 服务端 Reality 自动安装流程。

## 维护与验证

设置页提供“导出诊断”和“恢复连接状态”。导出只读、不含连接私钥或订阅。恢复会核实并断开本项目通道，保留 NinjaTrader 持久保护，不自动重连。无法核实身份时保留证据并停止；不对其他 VPN 做清理。

包内 `package.sha256` 检查完整性，ZIP 同时提供外部 SHA256。它们不等于应用代码签名。

此包已完成隔离回归与本地真实 TCP 协议验证。真实 Linux 系统部署、开机恢复、公网链路、行情、订单与小时级稳定性要在目标环境另外验收。发布准备没有安装到当前交易电脑，也没有切换其网络。

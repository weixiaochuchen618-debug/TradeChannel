## 2. 图形规范

### 2.1 结构
- 底板：墨蓝正圆 `#0F1A38`，r=122（viewBox 256）
- **八条腿（四对）**，左右对称，白色圆头折线——这是经过修正的版本（曾误画六条，已改）
- 身体：白色横椭圆 rx=45 ry=38
- 眼睛：两个墨蓝圆 + 左上有白色高光点（视线感来源，**不可去掉**）

### 2.2 色板（只这五种，无渐变、无投影）

| 用途 | 色值 | 说明 |
|---|---|---|
| 底板 | `#0F1A38` | 深海军蓝，所有尺寸同底 |
| 主图标体色 | `#FFFFFF` 白 | 任务栏/窗口/快捷方式/安装包——**固定，不随状态变** |
| Connected | `#22C55E` 绿 | 托盘·通道在跑 |
| 过渡态 | `#F5A524` 琥珀 | 托盘·正在连接/切换/断开 |
| 静默态 | `#98A2B3` 灰 | 托盘·未连接/未配置/故障/读取中（**默认色**） |

**换色规则**：只替换 `legs` 组的 `stroke` 与身体椭圆的 `fill`；底板、眼睛、高光永不变色。

### 2.3 尺寸分稿
- **32px 及以上**：通用稿 `zMaster`（八腿完整）
- **16/24px**：简化稿 `zMaster16`（腿部六段剪影、腿加粗 80%、眼睛放大取消高光）——直接缩放通用稿会糊，**必须分稿**
- 多尺寸 .ico 建议包含：16、24、32、48、64、128、256

## 3. 状态 × 颜色映射（严格绑定代码 StateKey）

> 代码位置：`TradeChannel.ps1` 的 `StateKey()` / `ObserveTrayState()`（RuntimePages.ps1）

| StateKey | 托盘体色 | 说明 |
|---|---|---|
| `Connected` | **绿** | 通道在跑。现有 `Overview.StateKey='Connected'` 且 `Running` 判断原样可用 |
| `Connecting` / `Applying` / `Disconnecting` | **琥珀** | 过渡态，`StateKey` 已统一返回这三个值 |
| `Disconnected` / `Unconfigured` / `Fault` / `Loading` | **灰**（默认） | Fault 不再用系统红错号。**注意：气球提醒逻辑（`ObserveTrayState` 的「非本意断开才弹气球」）必须保留，颜色降级≠通知降级** |

**两条纪律（用户确认）**：
1. 主程序图标（任务栏/窗口/快捷方式）**固定白蛛**，不随状态变色——变色只发生在托盘。
2. 琥珀在托盘=过渡；在界面正文里琥珀依然是 Tone.warn 警告色。两个区域靠位置区分，正文琥珀语义不改。

## 4. 实施顺序与验收

推荐按此顺序，每步独立可验：

1. **制作 .ico**（白蛛主图标 + 三色16/32/48）→ 放入 `assets/` 替换现 `TradeChannel.ico`
2. **嵌入**：exe 资源 / WPF `Window.Icon` / 托盘 `NotifyIcon` / 桌面快捷方式
   → 验收：任务栏不再显示 PowerShell 图标
3. **托盘变色**：`ObserveTrayState` 中按上表切换预渲染的三色 .ico；删掉 `SystemIcons.Error/Warning` 回退
4. **Hero 蛛**（可选 P0）：概览 Hero 左上的 56px 圆点换成蛛（颜色随三色映射）——代码 `Hero.Tone` ok→绿 / idle→灰 / warn→琥珀 / Fault→灰蛛（Hero 已有红色故障文案，蛛不再重复报警）

**全程不得触碰**：连接事务、网络配置、StateKey 定义、Tone 色板。本设计只改「怎么显示」，不改「状态是什么」。

## 5. 已知限制（如实记录）

- 蜘蛛为原创几何造型（八腿/头身比与任何知名形象均不同），但发布前建议商标近似检索（蜘蛛题材品牌存在，如 SilkSpider）
- 16px 简化稿经渲染验证可读；24px 介于两稿之间，建议用简化稿
- 浅色壁纸下任务栏的白蛛+墨蓝底对比充足，已模拟验证

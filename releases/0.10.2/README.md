# TradeChannel 0.10.2 预览版

本版把 TCP 穿透改为「自动准备 TCP 备用」：有对应参数时自动复用；没有时通过一次服务器管理登录，检查服务并取得原设备参数，必要时展示增量部署计划。软件自动生成备用配置，保留原 UDP 和设备身份；准备完成后另行确认启用。手工 UUID、公钥等表单保留在高级入口。

线路切换失败后提供分层检查及下一步引导。实际出口检查延长连接预算，并在首次失败后换用另一 HTTPS trace 核对，不把进程运行、端口可达或一次超时直接判定为可用／UDP 被阻断。验证和交付记录见工作区 `reports/release-0.10.2`。

本版修复状态刷新后滚动回到顶部的问题，窗口放大时内容随可用宽度扩展，小窗口自动调整流量选项和状态卡布局。在「设置 → 窗口与连接」选择关闭按钮的行为：默认收起到托盘，也可以退出管理界面；两种方式都保持后台连接。从托盘或桌面恢复时复用已打开的窗口。

本版覆盖自助部署、服务器和设备管理、离线设备邀请、独立候选验证，以及运行期报告、托盘故障提醒和配置还原。

完整解压到固定目录，运行 TradeChannel.exe。界面读取状态；部署和候选准备不会启用线路。连接、断开、切换仍需明确操作。

## 三个入口

- 第一次配置：购买准备、接入资料、程序内认证、环境检查、确认计划、自动授权与候选导入。
- 添加/更换线路：保留旧线路，继承有效偏好，重新取得服务器身份与授权。
- 连接已有服务器：管理电脑发邀请，新电脑返回申请，管理端批准并交回加密授权；新电脑自己合成配置。

Linux 自动部署面向 Ubuntu 24.04 / Debian 13 amd64、systemd 专用 VPS，需要 root 或已有非交互 sudo。Windows Server 和旧文件导入保留，能力按实际支持显示。

## 日常维护

部署页“我的服务器”管理设备、邀请、增量 TCP 和未完成操作。概览运行状况查看时间轴并导出 JSON/文字；线路“还原配置”核对历史配置，在线配置先安排维护。设置显示版本、程序位置和快捷方式/副本提示。

关闭窗口收起托盘后仍观察状态；异常不会自动重启或切换出口。新配置日志默认 warn，未来启动日志持续轮转；旧日志不在本次开发中清理。

## 验证与边界

0.10.0 的本机隔离协议验证使用真实 sing-box 跑通 UDP、VLESS/Reality 内嵌 WireGuard 与候选 DNS；不等于物理直连、服务器重启或交易业务验收。该轮服务器验证见工作区 reports/release-0.10.0/交付与验证说明.md；本轮窗口交互、完整包和 C 盘更新证据见 reports/release-0.10.1。

离线单机产品不检查在线更新、不管理云账单。卸载隧道服务不释放云资源或停止计费。

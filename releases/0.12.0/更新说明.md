# 0.12.0 预览版更新说明

基线：0.11.1。落实第八轮审查中的可达性选择、证据与状态闭环。

- 统一探测结果：配置、转发、路径证据、时效和清理分别记录。两种方式都失败或证据不足时允许无推荐，不再兜底推荐 UDP。
- 自动检查接入部署结束阶段。推荐写入本机线路默认值，连接预览与实际启用消费同一方式、配置哈希和证据；TCP 推荐不再读取 UDP 的汇总。
- 区分可达性推荐、默认策略、用户指定和旧配置默认。用户指定的下次连接方式不被新推荐覆盖，推荐更新不切换当前网络。
- 生成带网卡/DNS 绑定的新不可变配置，探针与正式运行使用相同绑定和引擎。旧配置、历史引用及当前运行资料保留。
- 按支持条件核对本次拥有的进程与实际网络观测。无法证明时降级；固定样本、超时、异常和清理结果全部保留，不按单次响应决定协议。
- 已连接线路按实际会话显示 UDP/TCP 与本次检查结果；兼容旧 manifest、批准运行副本和历史 profile，哈希不同的配置不继承旧验证。
- 完成页收敛为连接/稍后或重试/稍后。旧线路连接时自动登记资料；当前诊断通过后继续使用，备用补齐保持可选。
- 保留服务器增量部署、原设备复用、邀请加密交接、服务商、交易/AI 名单、任务管理、窗口托盘及失败事务核对能力。

本版采用基于证据的可达性选择，性能数据仅用于观察。独立探针不能代替实际 TUN、进程分流、重启和交易业务验收；实际支持范围和本次验证证据随交付报告提供。

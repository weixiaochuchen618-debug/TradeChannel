# TradeChannel 交易通道

Windows 桌面通道与分流管理项目，包含 PowerShell、C#、Python、WebView2 界面、Linux 部署代码、构建工具和测试。

**最新源码：0.23.4 预览版。** 本仓库只收录 0.23.4 一个版本的脱敏源码。早期版本（0.8.0–0.16.17）的源码与提交历史不在本仓库，只保留在作者本机工作目录。当前仓库由所有者选择公开，最新源码为预览版。构建验证、程序安装与真实服务器端到端验收分别记录。

第一次使用 GitHub，请先看 [GitHub 新手指南](docs/GitHub新手指南.md)。构建与验证方法见 [源码构建说明](docs/源码构建说明.md)，隐私处理见 [脱敏说明](docs/脱敏说明.md)。

## 项目能力

- 分别管理交易、日常上网和 AI 助手流量的出口。
- 自建服务器部署、SSH 身份核验、设备配对和线路管理。
- UDP/TCP 检测、默认协议选择、连接证据与失败恢复。
- 本地配置事务、运行诊断、线路保护和资料清理。

交易流量可按用户选择走自建线路或可用的服务商线路；日常流量也可选择本地直连。具体功能以当前版本源码与随版本指南为准。

## 使用与构建

本仓库的源码树排除了可执行文件、第三方 DLL、安装器和压缩包，安装包只作为 Releases 附件发布。运行环境是 Windows x64、Windows PowerShell 5.1 和 .NET Framework 4.8。网络及安装操作需要管理员权限。

需要自己从源码构建时，先按 [源码构建说明](docs/源码构建说明.md) 准备固定版本的依赖，再构建完整包。直接使用则下载 Releases 中的 ZIP，解压后运行 `TradeChannel.exe` 安装到 `C:\tradechannel`。

当前版本用户指引：[新手部署指南](releases/0.23.4/新手部署指南.md)、[Linux 部署指南](releases/0.23.4/Linux部署指南.md)、[更新说明](releases/0.23.4/更新说明.md)。文档中的版本状态和工作区报告链接只作为背景；原始现场报告含私有运行信息，没有上传。

# 上传范围和脱敏说明

本次按 2026-11-16 的开发目录整理，仓库只保留 0.23.4 一个版本。

## 包含和排除

仓库包含 `releases/0.23.4/` 共 432 个源码、界面、测试、指南、许可和图标文件，以及 `tools/`、`design-handoff/` 和本目录的说明文档。

2026-11-16 起，仓库不再保留 0.8.0–0.16.17 的历史版本目录、`product/` 历史基线及其提交历史；这些内容只保留在作者本机工作目录。仓库历史已重写为单个提交，旧提交不再出现在分支历史中，但按 GitHub 的行为，在回收前仍可用完整 SHA 直接访问。

排除以下内容：

- 真实运行配置、节点身份、凭据、私钥和导出文件。
- 原始 `reports/`、登录排查日志、现场截图及安装回退备份。
- EXE、DLL、压缩发行包、NuGet 下载缓存、测试库、测试运行产物与 Python 缓存。本次排除 30 个文件：`assets/sing-box.exe`、`assets/wg.exe`、`assets/wireguard-installer.exe`、`assets/lib/*.dll`、`assets/webview2/*.dll`、`runtime/*.dll`、`deployment/*.dll|*.exe`、`TradeChannel.exe`，以及 `package.sha256`、`package-metadata.json`、`package-leak-check.txt`。
- 原上传准备目录及既有 Git 历史，防止旧文件或旧提交元数据携带隐私信息。

这份仓库保存项目源码，不是电脑工作目录的逐文件镜像，也不是个人运行资料备份。

## 替换原则

真实服务器和曾观察到的出口地址统一替换到 RFC 5737 文档网段 `203.0.113.0/24` 或 `198.51.100.0/24`；源码与测试断言同时替换。个人工作区路径改为相对路径，涉及本机账户的测试路径改为 `ExampleUser`，真实机器名改为示例名。

本次具体替换：

| 原值 | 替换为 | 位置 |
|---|---|---|
| 观察到的出口 IPv4（含 `.178` 与前导零写法） | `203.0.113.177` / `203.0.113.178` / `203.044.113.177` | 测试与更新说明 |
| 自建服务器地址 | `203.0.113.21` | 线路恢复测试 |
| 更新说明中引用的出口地址 | `203.0.113.101` | `更新说明.md` |
| 线路标签中的服务商品牌 | `模拟香港主线` / `模拟测试线路` / `示例线路` | 界面与状态测试、更新说明 |
| 第二台电脑的真实设备名 | `EXAMPLE-PC` | 配对与加入测试 |
| 本机账户路径 | `C:\Users\ExampleUser\` | UI 测试与浏览器路径 |

要求通过“公网地址”校验的隔离测试采用公开 DNS 地址 `1.1.1.1` 和 `1.1.1.2` 作为模拟值；`test_linux_server.py` 的 `ProbeSourceIPv4` 需要 `is_global`，文档网段不满足该条件，因此该文件不用 RFC 5737 地址。非规范地址用例保留前导零（`1.1.1.01`），仍验证拒绝行为。没有为脱敏放宽生产代码的地址校验。

公共 DNS、标准网段、公开服务域名、第三方作者署名、版权邮箱和依赖校验哈希保留。模拟测试口令、随机生成的隔离测试身份、私钥格式标记用于测试安全处理，不属于可连接真实服务器的凭据。

## 提交与后续保护

仓库历史在 2026-11-16 重写为单个提交，只含 0.23.4 源码，使用 GitHub `noreply` 邮箱提交。仓库由所有者选择保持公开；本次只保留脱敏源码，未添加协作者、未发布可执行程序。

早期版本源码中曾有一处服务商品牌名残留在测试夹具与更新说明里，随历史重写一并消失。以后新增版本时仍需逐次扫描，不能只依赖忽略规则。

`.gitignore` 排除常见凭据、日志和构建产物，但不能识别写进源码里的新秘密。每次更新仍需扫描和复查，不能只依赖仓库私有性或忽略规则。

检查结论与具体覆盖范围见同目录的 `上传验证记录.md`。没有上传原始现场报告，其中的历史文件链接只作本机历史引用。

# 更换服务商与接入 Clash Verge

TradeChannel 管理流量的去向，代理客户端管理订阅和节点。香港、美国等自建线路与服务商独立；更换订阅不需要重装 TradeChannel，也不需要复制订阅密码到本工具。

## 推荐用法

在 Clash Verge 中导入服务商提供的订阅并选择节点。TradeChannel 中「交易」保持自建线路，「日常上网」选择 Clash Verge，「AI 助手」可按名单选择走交易线路。需要整机经香港时，把日常上网改为「走交易线路」。

国内直连还是代理由 Clash 的规则决定。TradeChannel 优先匹配交易和已勾选的 AI 助手，再把其他流量交给日常端口。BatVPN 仍然可用；工具也支持无认证、仅监听本机的 SOCKS5 客户端用于日常上网。自定义客户端的交易策略暂时不能自动核验，因此当前不作为交易备用；更换服务商订阅可优先通过 Clash Verge 接入。

## 第一次接入

1. 打开「线路」页的服务商区域，点击自动发现。选择 Clash Verge 或 BatVPN 后登记。登记只保存资料，不切换网络。
2. Clash Verge 选择「自动准备」。工具在备份后写入域名识别和独立的交易备用端口；遇到已有自定义配置冲突会说明原因并保留原文件，不覆盖订阅。
3. 若客户端正在承载交易或日常流量，准备操作会停止在提示页面，要求先将交易切回自建线路、日常改直连。切勿让两套 TUN 同时工作。
4. 客户端要保持系统代理、TUN、代理守卫关闭，日常保持规则模式。自动准备后按结果提示完成客户端重新加载；软件未确认的状态不会显示为通过。
5. 新增服务商需更新线路配置。**这一项会重启通道，也会中断依赖通道的 AI 助手连接。** 在可以暂停连接的维护窗口进行，先退出整个 NinjaTrader；不要在交易或 agent 正在工作时升级。
6. 更新后点击服务商「检查」。端口归属、客户端状态与实际转发通过后，再选择日常服务商。已应用的服务商之间切换日常出口，无需重启交易通道。

如果暂时不能中断香港主线，可以完成发现、登记和静态检查；保持当前通道运行，留到维护窗口再更新。工具不会为了登记新服务商自动切线。

## 更换订阅

在同一个 Clash Verge 内更换订阅，通常保持本机日常端口不变。换订阅后重新执行自动准备和检查，尤其核对备用端口所用的节点组：新订阅可能没有原来的组。上游节点域名变化时，也可能需要更新通道的独立 DNS 配置，工具会显示待应用。已开启 TUN、变更监听端口或移动程序目录时，不能沿用旧的检查结果。

**独立端口不等于交易已经验收。** 节点组可能选中 DIRECT 或 REJECT；端口通了也可能无法稳定加载 NinjaTrader 历史数据。实际出口、登录、实时行情、历史图表和订单回报应分别确认。本工具不替你下单。

## 香港故障时

准备好备用客户端，检查通过后在「交易」中手动选择该服务商并确认。连接会重新建立，NinjaTrader 需重连。没有自动故障切换或自动回切。

Clash Verge 的日常端口保留规则分流；交易备用端口指定节点或节点组，但仍需检查实际出口。BatVPN 若共用日常端口，作为交易备用前要先切为其内部全局模式。备用检查失败时保留当前交易出口。

## 恢复与迁移

- 服务商页提供恢复自动准备前配置的入口。恢复不会改订阅，也不会自动切换香港线路；若用户后来改过相同文件，先提示冲突，避免覆盖。
- 设置迁移只带名称、客户端类型等参考，不包含订阅 URL、密码或节点密钥，也不在新电脑直接激活旧端口。新电脑须安装客户端、导入自己的订阅并重新识别端口。
- 退出 TradeChannel 界面不会停通道；「断开」才停止通道并保留 NinjaTrader 保护。重启电脑后手动连接。

## 当前版本的验证边界

0.7.1 的隔离验证与本机只读证据另见项目报告。新版软件与新版线路配置是两件事：安装新版界面不会自动升级在线配置。真实服务商出口、故障切换和完整交易时段必须在允许中断的窗口完成；不能把测试夹具或语法检查当作线上交易验收。

# TradeChannel 0.14.3 默认推荐连接修复

- 修复检测已经通过、推荐仍有效，却在连接时误报“推荐已过期”的问题。连接事务现在接受检测模块生成的性能对比推荐（Performance）与稳定性推荐（Stability），与原有可达性推荐及默认策略保持一致。
- 推荐必须继续通过原有完整证据校验：时效、实际配置哈希、设备路径、网络环境、检测数据摘要和探针清理结果。没有增加自动切换或放宽失效结果的资格。
- 无法识别的推荐来源、配置不匹配与真实到期分开提示，避免把所有失败都说成“过期”。
- 增加真实推荐生成器到默认连接事务的回归，覆盖 UDP/TCP 性能与稳定性选择、失效证据阻断、预览后变化、目标验证失败及原连接恢复。

本版本沿用 0.14.2 的双协议部署与检测、线路管理、托盘状态和窗口交互。已部署的 UDP/TCP 配置与设备授权无需重建。实际启用仍由用户确认；检测通过不能替代 NinjaTrader 登录、行情及历史数据验收。

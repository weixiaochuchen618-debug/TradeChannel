# TradeChannel 0.14.3 预览版

0.14.3 修复了“性能/稳定性推荐有效但连接被误报过期”的问题，已准备的线路无需重新部署。推荐真实到期时可重新检查，或从“连接方式”明确选择已保存的 UDP/TCP；实际启用仍需确认。

完整解压到固定目录后运行 TradeChannel.exe，允许本机管理权限。打开管理界面只读取当前状态；连接、断开和换线由用户明确操作。

概览显示交易通道是否运行、当前连接方式和三类流量走向。绿蛛只表示通道运行，出口检查与交易登录、行情、订单和 AI 平台可用性分别验收。故障图标带感叹号，明确的错误原因保留在概览和运行诊断中。

选中项采用蓝底白字与勾选。日常和 AI 的分流偏好沿用已有配置；更换交易线路或 UDP/TCP 会先预览、确认并执行原有受控切换。已经备齐两种协议的线路，日常使用不需要再登录服务器补部署。

“检查出口”显示交易和日常的实测 IP 与检查时间；AI 出口按分流规则推断。旧会话、旧配置或超过十分钟的检查不会继续显示为当前通过结果。

关闭方式在设置页选择。收起到托盘或“退出界面（连接保持）”不停止后台通道；重启电脑后需手动连接。托盘保留打开控制台、查看运行诊断和退出界面入口。

首次部署、新电脑接入、设备授权、维护与恢复请参阅新手部署指南.md、Linux部署指南.md和快速部署.html。

新增或更换线路会在同一线路内准备 UDP/TCP，自动准备检测网卡及实际外层/DNS 绑定，再交替采样、核验检测路径与出口并给出默认建议。配置备齐、网络检查与实际启用分别显示；异常提供网卡选择、诊断和已准备方式的手动试用入口。完成页“完成，保留当前连接”保存结果，真正启用仍需明确确认。

重新检查沿用原设备身份与部署任务，只处理本机候选，不要求重复授权或安装服务器。已登记服务器重装可从“我的服务器”明确重新核验新 SSH 指纹，认证后建立新的管理身份并归档旧记录；旧任务及授权不能续接到新服务器。

软件依赖和校验：
- 必需二进制、Framework 依赖和许可证全部内置。
- package.sha256 校验解压文件；更改程序文件后需重新构建。
- version.json 是版本来源。
- 自检：TradeChannel.exe --self-test --output 指定输出目录。自检使用临时数据并阻止真实 Worker 调度。
- SVG 和图标生成脚本随包保存；图标已预渲染，用户无需安装 Python、Chrome 或 Playwright。
任务栏右下角状态徽标与窗口、托盘图标同步为绿／琥珀／灰，故障保留感叹号。任务栏徽标使用Windows状态叠加接口，保留应用分组及固定入口；Windows“小图标任务栏”不显示叠加状态，可查看托盘和概览。本机诊断文件 diagnostics/icon-state.json 记录本软件使用的显示源及徽标状态，无连接凭据。

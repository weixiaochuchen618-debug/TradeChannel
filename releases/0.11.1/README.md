# TradeChannel 0.11.1 预览版

完整解压到固定目录，双击 **TradeChannel.exe**。打开界面只读取状态，不自动连接、断开、切换或迁移正在使用的配置。

故障任务核对：出现提示时点击“核对当前状态”。仅在通道已停止且原配置完整时结束故障记录，不自动重连。

## 这版的使用方式

- **第一次配置**：默认标准部署。同一认证任务内先完成 UDP，随后尝试准备 TCP 备用；普通备用失败经 UDP 复核后带警告交付，未知事务先处理恢复。
- **日常连接**：选择一条服务器线路。UDP 与 TCP 是线路的连接方式，不再生成另一条“TCP 备用”用户线路。
- **补齐备用**：已有参数直接复用；必要时优先使用已保存的加密管理访问，没有有效凭据时才要求登录。原设备授权保持。
- **更换连接方式**：在线路页打开“连接方式…”，核对目标再“切换并验证”。先退出整个 NinjaTrader；切换会短暂中断通道，失败按原状态恢复并复测。
- **旧版资料**：有明确来源与一致身份的 TCP 兄弟记录显示为同一线路的两套配置；歧义记录保留。活动引用不因页面读取或资料整理而变化。

“配置已准备”“当前环境转发通过”“本地直连通过”和交易登录/行情/订单是不同结果。TCP 增加可达性选择，不代表性能升级。

购买、首次身份核对和云规则仍需对应账户权限。软件提供统一端口清单，不自动修改云规则、付款或管理账单。新电脑继续通过原邀请与加密授权接入，V1 签名契约保留，双方式资料形成版本化本机 bundle。

界面与通道进程独立。关闭方式在设置页选择，默认托盘，也可退出界面并保持连接；重启后按原策略手动连接。不提供静默协议故障转移。

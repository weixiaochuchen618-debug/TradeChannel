# 第一次使用 GitHub

这个仓库是代码备份和版本管理空间。你可以在 GitHub 网页里查看、下载和比较代码；上传源码不会自动安装程序，也不会修改电脑的网络设置。

## 查看和下载

1. 打开本仓库。当前由所有者选择为 **Public（公开）**，任何人都可以查看上传的脱敏源码。
2. 首页显示项目说明。点击 `releases`，再点击 `0.16.14`，可查看最新源码。其余版本用于历史对照。
3. 点击绿色 **Code** → **Download ZIP**，下载当前分支的全部源码；解压后按源码构建说明使用。
4. 点击 **Commits** 查看修改记录，打开某次提交可比较改动。主分支为 `main`。

## 后续更新

本机开发目录与这份脱敏上传副本分开保存。以后修改原项目，并不会自动更新 GitHub。每次上传都要重新同步源码、脱敏、检查，再提交和推送。不要直接把整个桌面开发目录拖到 GitHub：其中可能包含真实运行资料。

需要更新时，可以告诉协作助手：“把 TradeChannel 最新源码脱敏后同步到现有 GitHub 仓库，保留历史提交。”无需重新创建仓库。

本机 `github-source/` 是这次整理的 Git 工作副本。熟悉 Git 后，在该目录可用以下只读命令查看状态：

```powershell
git status
git log --oneline -5
git remote -v
```

## 分享和访问

当前仓库链接可公开查看。确需授予修改权限时，在 **Settings → Collaborators** 邀请指定 GitHub 账户；不要发送密码或访问令牌。代码可见性与写入权限分别管理。

GitHub 登录、浏览器登录和 Git 上传凭据可能需要分别授权。浏览器显示登录成功后，以实际能读取仓库和推送代码为准。提交邮箱使用 GitHub 的 `noreply` 隐私邮箱。

## 备份边界

本仓库备份的是脱敏源码，包含构建工具、测试和资源，不包含真实线路、服务器密码、设备私钥和本机运行记录。个人配置如需备份，应另行加密保管；它们不应放进代码仓库。源码 ZIP 也不是可直接安装的程序包。

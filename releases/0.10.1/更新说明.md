# 0.10.1 预览版更新说明

基线为 0.10.0。本轮修复窗口交互，部署、服务器和传输协议保持原有能力。

## 窗口交互修复

- 状态刷新保留当前阅读位置；在页面末尾阅读时保留末尾锚点。连接数与连接时长原位更新，避免每次重建页面。切换页面后从顶部开始，过期的滚动恢复回调不会影响新页面。
- 解除内容区的固定宽度限制。窄窗口把流量选项放到说明下方、状态卡调整为两列；宽窗口使用可用宽度并恢复横向布局。
- 在「设置 → 窗口与连接」选择关闭按钮行为：默认「收起到托盘」，或「退出界面，连接保持」。两者都不停止通道，也不切换出口。
- 从托盘或桌面唤醒时复用窗口、页面与控件，保留最大化状态。已选退出界面但任务尚在运行时，窗口先收起到托盘，任务完成后再退出。
- 主窗口改用独立消息循环，隐藏到托盘不会结束界面进程；只有退出界面时才释放窗口循环和本机界面锁。
- 关闭偏好独立保存到 `ui-window-settings.json`，不改变连接偏好；损坏记录保留并使用默认托盘行为。

源码、完整包启动器和 C 盘安装验证记录见工作区 `reports/release-0.10.1`。本轮验证不切换当前线路或重启现用通道。

## 保留的 0.10.0 能力

以下能力来自 0.10.0，在 0.9.3 基础上实现。

## 部署与管理

新增状态驱动流程、持久化运行、原申请复用、批准摘要和结果未知时的核对。程序内 SSH 认证可多阶段复用；秘密经受限管道传给执行器，不进 Worker 请求、命令行或日志。已知主机身份变化阻断。

购买和安全组仍在云控制台完成；不支持或手工环境不会自动覆盖。“我的服务器”管理设备、邀请和维护；新电脑生成独立 WireGuard 身份，管理端提交它的申请，并把签名授权加密给它。管理端不持有新电脑私钥。

既有 UDP 增加 TCP 采用增量计划，保留 WireGuard 身份与设备，变更影响由预览展示。旧连接材料保留；新增管理能力需显式升级和能力协商。

## 候选与运行期

候选使用用户态 WireGuard、认证回环入口、自己的 DNS和出站，测试完整 UDP/TCP、TLS和出口。拒绝与本机在用身份并行测试。

候选转发和外层物理路径分别验证；不能证明物理直连时保留 ExistingSystemRoute / Inconclusive。Cloudflare 验证、HTTP403、DNS/TLS/连接失败分开分类。

托盘隐藏仍观察，状态变化单次通知；主动断开不报警，保护未知不保证“仍生效”。运行监督器持久化生命周期，报告提供事件时间轴、来源标注和可读导出；控制器选择不当作实测 IP。

新配置默认 warn；未来启动日志单流约4 MiB/段、最多3段、保留4个本工具会话。旧生产日志和当前配置不在开发时修改。

配置还原有哈希/状态保护，在线需明确停止；未连接线路只还原引用，不自动连接。安装发现只查有限位置与快捷方式，大小写去重，不全盘扫描或删除副本。version.json 为版本来源。

## 边界与验收

TCP 外层 UUID仍由服务器共用，撤权取消独立 WireGuard 身份，不轮换共享 UUID影响其他设备。

设置迁移与密码加密管理恢复包分开；导入仍需核验身份。没有管理凭据或云恢复权限时不能绕过授权找回。

验证按源码、Framework依赖、SSH协议、跨端加密、断点流程、协议转发、真实服务器、界面、包与启动器分层记录。最终报告见 reports/release-0.10.0；缺失的真实验收不计为通过。

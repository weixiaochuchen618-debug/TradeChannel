# TradeChannel 0.16.1 记录管理补丁

- 部署中心的“需要处理”“继续准备”和草稿记录增加“删除记录…”入口。
- 操作历史增加单条删除、多选删除、“全选当前结果 / 取消全选”及选中数量；全选仅针对当前筛选结果。“已放弃的添加”也使用同一套选择和删除功能。
- 删除前显示具体记录与数量，确认后从列表移除。原部署资料、线路和密钥保留，当前服务继续运行。
- 打开“显示已删除记录”可恢复原记录；旧版隐藏记录也使用这个恢复入口。独立服务器登记和未完成的准备记录都可管理。
- 资料保留保护与列表删除分开。历史引用异常、身份缺失或仍有恢复资料，不再让删除入口消失；正在执行的任务显示暂不能删除的原因。
- 新进度会使旧删除标记失效并重新显示。删除准备记录后，同一次添加不会重新生成空服务器卡片。已保存线路保持可用。
- 删除和恢复回调保持当前页面；只读窗口禁用相关操作。历史页从同一份查询结果显示普通记录与已放弃记录。

本版沿用 0.16.0 的部署中心分组、草稿放弃与恢复填写、从具体线路进入服务器维护，以及顶部可见的购买准备、迁移、Windows Server 部署和管理恢复工具。线路、部署授权、设备身份与远端操作仍使用原有核验。

验证包含真实模块、独立 Worker 进程、实际 WPF 控件流程、解压包与安装版自测。所有删除/恢复测试使用隔离数据；用户现有记录由用户自行选择管理。真实服务器部署、授权、撤销和线路切换不属于本次补丁验证范围。

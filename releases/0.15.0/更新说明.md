# TradeChannel 0.15.0 部署体验与恢复改进

- 主入口统一为“添加线路”，自动识别已有本机组件、已知服务器和接入资料类型。密码与私钥登录分开，用户名、端口和高级选项按需展开。
- 保留异步刷新前的非敏感输入及当前密码控件；登录失败、指纹变化和应用环境重置在同一向导处理。一次明确的准备范围内自动推进，影响扩大或身份变化时重新核对。
- 完整准备自动保存，退出完成页不再遗失状态。部分配置、未知结果、清理未完成和没有合格推荐仍明确提示，不能被“已保存”遮盖。
- 默认连接与短期推荐分离；可信默认可在推荐过期后明确使用，连接时保留全部事务保护和出口验收。当前活动身份不并行探测。
- SSH 与应用身份分层核验，支持同指纹应用重置及仅更新主机密钥；历史授权、任务和新服务器世代保持正确关系。
- 部署中心与操作历史统一，提供筛选、公开记录导出、单条/批量清理和恢复显示。受保护记录不清除，不删除底层配置、私钥或授权。
- 新电脑/管理电脑分别显示当前接入步骤；验签后自动匹配唯一管理目标。原申请授权重试和加密交接继续复用原设备。
- 签名授权 V2 可携带服务器实际 TLS 出口证据，绑定服务器、邀请、原申请和设备；缺少真实证据保留 V1，不伪造本机可用性。

沿用已准备的 UDP/TCP 配置、服务商与流量偏好，不自动断开或切换现有线路。实际服务器写操作、设备授权和接管本机网络按具体目标确认。

验证层次与本次尚未验证的真实场景见随交付的发布报告；界面模拟、本地协议回环、服务器只读状态不能互相替代。

# TradeChannel 0.9.3 · 交易通道

完整解压到固定目录，双击 **TradeChannel.exe**。完整包已包含二进制组件，无需编译或从旧版本同步。打开界面只读取状态，不会自动连接、断开或切换网络。

本版新增服务商编辑/删除/刷新路径、交易域名与任务归档管理，扩展 AI 名单，并修复失效服务商导致自动导入失败。在 0.9.2 基础上保留此前针对 0.9.1 的旧 TCP 升级、配置回滚、节点删除、部署自动导入、服务商偏好、服务器识别、指纹处理与诊断问题，并提供可选 Linux TCP 部署。详情见 [更新与升级说明](更新说明.md)。

交易、日常上网和 AI 助手的出口独立选择。日常/助手选择不改交易出口；换交易线路需要确认并先退出整个 NinjaTrader。手动断开保留交易保护，关闭窗口可收起到托盘，重启电脑后手动连接。

新 Linux VPS 可以在向导选择 UDP 或 TCP。已部署的服务器为每台新电脑新增独立 WireGuard 授权。已有 TCP 服务的参数可在线路设置表单填写，不能用另一台服务器的凭据。

“已部署”“配置校验通过”“TCP 端口可达”分别表示对应层的结果；实际出口、行情、订单及重启恢复仍需检查。源码与隔离测试随包提供。当前版本保持预览状态。
